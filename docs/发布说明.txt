一、这是什么
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
给游戏添加一整套可自由扩展的装备系统：

◆ 武器系统
  钝器 / 利器 / 枪械 / 徒手四种类型，内置 37 件武器（18 近战 + 13 枪械 + 6 护甲），
  商店分类购买，衣柜装备 / 卸下 / 丢弃，侧栏实时显示当前武器。

◆ 枪械系统
  16 种口径弹药（带子弹图标、穿甲等级颜色标注），
  每场战斗首枪消耗 1 盒弹药，没弹药自动切换副武器；
  累计消费 £6000 解锁枪械与军用装备；PG-7VM 火箭弹群体伤害。

◆ 护甲系统
  属性抗性：疼痛 / 压力 / 创伤 / 自控（方向感知，只挡该挡的方向），
  耐久磨损（归零永久损坏），寄修服务（1 天返回衣柜，费率按耐久分档）。

◆ 武器编制器（网页版，单文件）
  自由创建 / 修改武器与护甲（可自定义图片），一键导出武器包 zip 分享；
  支持导入已有武器包改包 / 拼包；编辑内容自动保存到浏览器本地，不怕误关页面。

◆ 游戏内编制器（工作台）
  创建自定义武器加入商店；v2.5.20 起可修改【已加载武器】的数值
  （内置 / 武器包货架模板，改动随存档保存，只影响之后购买；已购副本不变），
  内置 / 包武器可一键恢复默认，自定义武器可删除。

◆ 兼容中文汉化
  装汉化 mod（ModI18N 等）也能正常在商业街看到武器店入口。

二、怎么安装
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 先装基础 mod：武器系统mod_v2.5.20_适配DoLP0.768.zip（游戏内 ModLoader 导入）
2. 再装武器包（例如编制器导出的 weapon_pack_xxx.zip）——顺序不能反，装反包会被禁用
3. 进游戏 → 商业街（High Street）→ 可访问地点 → 武器店

★ 原版 DoL 0.5.11.9（含 mod loader 的官方/汉化构建）请用：
  武器系统mod_v2.5.20_适配原版DoL0.5.11.9.zip + 武器编制器-原版.html
  原版差异：挂钩属性为 体能(15000)/运动(1000)/格斗技巧 handskill(1000) 三项，
  内置 5 件徒手武器已映射为 handskill；其余机制与 DoLP 版完全一致。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、编制器怎么用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 双击用浏览器打开「武器编制器.html」（DoLP 版）或「武器编制器-原版.html」（原版版）
2. 填武器包名 → 点「＋添加武器」逐件编辑 → 点「📦 导出武器包 (zip)」
3. 把导出的 weapon_pack_xxx.zip 按上面顺序装进游戏
4. 也可以「📥 导入武器包 (zip)」：把已有武器包导进来改 / 拼包
5. 列表自动保存到浏览器本地；导出的 zip 才是真正的备份
