# Weapon Gear — DoL 武器 / 枪械 / 护甲系统 Mod

> English: [README.en.md](README.en.md)
> 📥 最新版下载：https://github.com/Qiufeng258/weapon-gear-mod/releases

机制型装备扩展：**不渲染贴图，只加数值与玩法**。内置游戏内编制器 + 网页版编制器，支持自定义武器包分享。

## 特性一览

- **武器系统** — 钝器 / 利器 / 枪械 / 徒手 4 类，内置 37 件（18 近战 + 13 枪械 + 6 护甲）；商店分类 / 分页 / 数值卡片；衣柜装备 / 卸下 / 丢弃 / 副武器；侧栏实时显示。
- **枪械系统** — 16 口径弹药（子弹图标 + 穿甲等级 0–6 配色；穿甲为预留展示，暂无具体机制）；每场战斗首枪消耗 1 盒；无弹药自动切副武器；累计消费 + 现金 ≥ £6,000 解锁枪械与军用护甲；PG-7VM 火箭弹群体伤害。
- **护甲系统** — 疼痛 / 压力 / 创伤 / 自控四维抗性（方向感知：坏属性只挡增加、自控只挡损失）；耐久磨损（归零永久损坏）；寄修（1 天返回，费率按耐久上限分档）。
- **编制器** —
  - 游戏内工作台：自由创建武器加入商店；**v2.5.20 起可修改已加载武器数值**（内置 / 武器包货架模板，overrides 随存档保存，可一键恢复默认；已购副本保持快照）。
  - 网页版：导入 / 导出武器包 zip、浏览器自动存档、实时数值预览、战斗参考面板。
- **武器包生态** — 导出 `weapon_pack_*.zip` 分享；包依赖 `weapon_gear ^2.0.0`，先装基础 mod 再装包。
- **汉化兼容** — 商店入口运行时注入；所有补丁锚点语言无关（锚代码不锚文本），汉化 mod 下同样生效。

## 兼容性

| 目标 | 状态 | 说明 |
|---|---|---|
| DoL 0.5.12.13（Lyra 1.0.1a / goose 1004.1） | ✅ 完整支持 | **v2.5.22 起**；伤害锚点跟随新版写法（详见下方「0.5.12.13 适配说明」） |
| DoLP v0.768 goosefem_mys 0.5.11.9 | ✅ 完整支持 | 全部机制（属性含斗殴 / 步法 / 打击 / 踢击） |
| 官方 DoL 0.5.11.9（含 mod loader 构建） | ✅ 完整支持 | 属性收敛为原版三项：体能(0–15000) / 运动(0–1000) / 格斗技巧 handskill(0–1000)，徒手武器自动映射 |
| 其他版本 / 其他 fork | 🟡 可尝试 | 一般来说不会出现重大问题；如遇异常再跑锚点校验定位 |

**我们改了什么、没改什么：**

1. 数值入口 / 出口的**守卫式钩子**（只做加法）：
   - 包裹 `pain / stress / trauma / arousal / control` 五个属性函数——仅当身穿护甲且伤害方向符合时按抗性减伤，不拦截、不改写原逻辑；
   - 战斗 `<<violence>>` 组件的疼痛 / 压力直改行、挣扎掉血两处、NPC 伤害分流（AOE）——同样是“有护甲才生效”的补丁。
2. 商业街入口：**运行时注入**武器店链接——定位的是 DOM 结构（`a[data-passage="Office Lobby"]` 等 data-passage 属性），不是翻译文本，所以汉化环境照样出现；标签文字按语言自动切换（中文“武器店 (0:01)” / 英文 "Weapon Shop (0:01)"）。

mod 通过加载器在内存中打补丁，**不修改游戏源文件**，卸载即还原。

## 安装

1. 按你的游戏版本选 zip：
   - **DoL 0.5.12.13（Lyra / goose 构建）**：`dist/DoL0.5.12.13/武器系统mod_v2.5.22_适配DoL0.5.12.13.zip`
   - DoLP v0.768：`dist/DoLP/武器系统mod_v2.5.20_适配DoLP0.768.zip`
   - 原版 DoL 0.5.11.9：`dist/原版DoL/武器系统mod_v2.5.20_适配原版DoL0.5.11.9.zip`
2. 游戏内 ModLoader → 添加 / 移除 Mod → 选择文件 → 添加旁加载 → 刷新页面。
3. （可选）再装武器包：必须先装基础 mod；包依赖 `weapon_gear ^2.0.0`，顺序反了包会被禁用。
4. 进游戏 → 商业街（High Street）→ 可访问地点 → 武器店 / 武器工作台 / 武器衣柜。

## 编制器

- **网页版**（浏览器直接打开）：
  - `dist/DoL0.5.12.13/武器编制器.html` — **DoL 0.5.12.13 版**：可挂钩属性收敛为体能 / 运动 / 格斗技巧（新版没有 brawling 等变量）
  - `dist/DoLP/武器编制器.html` — DoLP 版（属性含斗殴 / 步法 / 打击 / 踢击）
  - `dist/原版DoL/武器编制器-原版.html` — 原版 DoL 版（属性三项 / 体能上限 15000）

  用法（三版一致）：

  1. 填武器包名 → ＋添加武器逐件编辑（名称 / 类型 / 伤害 / 倍率 / 属性挂钩 / 价格 / 口径 / 护甲数值 / 图片）→ 📦 导出武器包 zip；
  2. 📥 可导入已有武器包改包 / 拼包；
  3. 内容自动保存浏览器本地；导出 zip 才是真正的备份。
- **游戏内工作台**：创建自定义武器；对已加载武器点「修改」改数值、「恢复默认」还原；自定义武器可删除。

## 0.5.12.13 适配说明（v2.5.22）

0.5.12.13（Lyra 1.0.1a / goose 1004.1 构建）与 0.5.11.9 相比，**本 mod 的 15 条补丁里 13 条原样命中**，实际改动只有两处：

1. **核心伤害锚点被改写。** `Widgets` 的 `defiance` 组件里，旧版是
   `<<set _thedamage to (2 * _defiance * (currentSkillValue('physique') / 4000))>>`，
   新版换成 `<<set _thedamage to (2 * _defiance * ($physique / 4000))>>`。
   武器加成是插在 `_thedamage` 赋值之后、扣血之前，所以只更新锚点，插入逻辑不变（枪械首枪耗弹 / 伤害倍率 / 数值守卫全部照旧）。
2. **`struggle_defense_result` 组件整块被删除。** 旧版"连续格挡 3 次后敌人力竭扣 1 血"的机制（`$struggle.enemy[_i].dodge`）在 0.5.12.13 里已不存在（全游戏 0 处引用），对应那条挣扎加成补丁没有锚点可打，直接移除；**剩余两处挣扎扣血仍在 `Widgets Struggle`**，加成照常生效。

适配后的全量核对（与 0.5.11.9 逐项对比）：

- 5 条 JS 属性钩子（`pain / stress / trauma / arousal / control`）全部命中；
- 直接写 `$pain +=` 6 处、`$stress +=` 16 处，与旧版完全一致 → 护甲钩子覆盖范围不变，没有新增"绕过护甲"的出口；
- 玩家对敌伤害出口集合只差 `Math.round(_thedamage)` 变 `_thedamage` 一条，仍在被补丁包裹的同一组件内 → 覆盖；
- `printmoney`（便士 ÷100）、`linkifyDivs`、`createInternalLink`、`Links.generateLinkNumbers`、`Time.pass`、`currentSkillValue` 均仍存在，商业街入口注入与货币换算不需要改；
- 段落 / widget 名无冲突（游戏 16,087 段落、5,101 widget）。

**已知（非本版回归）**：内置 37 件里有 5 件挂了 `brawling` 属性（5 把徒手武器：黄铜指虎 / 战术指虎 / 单指拳刃 / 双刃拳刺 / 腕戴式爪刃），
它们在 0.5.11.9 就已经没有对应变量（`currentSkillValue` 恒返回 0），0.5.12.13 连 `$brawling` 这个 feat 变量也删了 → 这条挂钩等于 +0，不影响其他机制。

- **网页编制器**已经按新版收敛：`dist/DoL0.5.12.13/武器编制器.html` 只提供 体能 / 运动 / 格斗技巧 三个可挂钩属性，新建武器不会挂到死属性上。
- **游戏内工作台**的属性选项仍是旧列表（含 brawling / footwork / striking / kicking），选中同样 +0；要不要一起收敛、以及那 5 件内置徒手武器是否要改挂 `athletics`（会实质提升徒手伤害，+20~100）都还没动，等你拍板。

**旧版本不会被替代**：DoLP 0.768 与原版 0.5.11.9 的锚点与新版不同，请继续用对应的 v2.5.20 / v2.5.21 包，**不要混装**。

## 注意事项

- 武器包依赖 `weapon_gear ^2.0.0`；先装基础 mod。
- 修改货架模板只影响**之后**购买；已购武器是购买时的快照。
- 网页编制器自动存档跟随浏览器；清除浏览器数据会丢（导出 zip 才是备份）。
- 枪械默认 £6,000 解锁（可改源码 `weaponGearUnlockGuns` 后重打包）。
